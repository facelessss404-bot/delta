3. AUTHORITY HIERARCHY
======================

There are exactly three roles:

1. TRAINING COMMANDER

   * Highest authority
   * Super user

2. ADMIN

   * Operational administrator
   * Below Training Commander

3. CADET

   * End user
   * Can view only their own official records
   * Can submit their own physical evidence

The role hierarchy must be enforced on the BACKEND.

Frontend button hiding is NOT security.

Every protected API endpoint must:

* verify authentication
* verify role
* verify ownership where appropriate
* reject unauthorized access

A Cadet must never be able to access another Cadet's records by manually changing an ID in the URL or API request.

11. PHYSICAL TRAINING / VIDEO UPLOAD
====================================

Physical Training must be a separate module.

Cadets must be able to upload evidence for:

* Morning Run
* Physical Training
* other configured physical activities

The frontend must support device/mobile video selection.

Upload flow:

1. Cadet selects activity.
2. Cadet selects/records date.
3. Frontend asks backend for a presigned upload URL.
4. Backend generates secure presigned S3 upload URL.
5. Frontend uploads directly to private AWS S3.
6. Frontend notifies backend that upload completed.
7. Backend stores metadata in MongoDB.

Do NOT store video binaries inside MongoDB.

MongoDB stores metadata such as:

* cadetId
* activityType
* date
* s3ObjectKey
* filename
* MIME type
* size
* uploadStatus
* reviewStatus
* reviewedBy
* reviewedAt
* comment

S3 bucket must remain private.

Never expose permanent public video URLs.

When an authorized user views a video, backend should generate a short-lived signed viewing URL.

Required API concepts:

POST /api/physical/presign
POST /api/physical/complete
GET /api/physical/my
GET /api/physical/cadet/:cadetId
PATCH /api/physical/:id/review

Review statuses:

* Pending
* Accepted
* Rejected

Commander/Admin can:

* view submissions
* review submissions
* change status
* add comments

Cadets can:

* upload
* view upload history
* see status
* see feedback

Show upload progress.
